# Movie Ticket Management System

## # Problem Statement

* Managing movie ticket bookings manually can be difficult and time-consuming.
* Users need a simple way to book, search, view, and cancel movie tickets.
* Administrators need to manage bookings, movies, and booking statistics efficiently.
* This project provides a simple Python-based solution for these requirements.

## # Scope

* User and administrator login.
* Movie listing and movie management.
* Movie ticket booking.
* Ticket searching and cancellation.
* Viewing user bookings.
* Booking statistics for administrators.
* The current system uses in-memory data storage.

## # Target Users

* **Users/Customers:** Book and manage their movie tickets.
* **Administrators:** Manage movies, bookings, cancellations, and statistics.

## # High-Level Features

* User authentication.
* Admin authentication.
* Movie selection.
* Ticket booking.
* Ticket search.
* Ticket cancellation.
* View bookings.
* Add movies.
* Booking statistics.
* Input validation and error handling.

## Movie Ticket Management System

# Overview

* Python-based console application.
* Manages movie ticket bookings.
* Provides separate **User** and **Admin** access.

#  Features

##  User

* Login
* View available movies
* Book tickets
* View bookings
* Search tickets
* Cancel own tickets
* Logout

##  Admin

* Login
* View all bookings
* Search tickets
* Cancel bookings
* View statistics
* Add new movies
* Logout

#  Technologies Used

* Python 3
* Lists and Dictionaries
* Functions
* tuples
* Sets

* Loops
* Conditional Statements
* Exception Handling
* Git & GitHub

#  Installation & Run

* Clone the repository:

```bash
git clone <YOUR-GITHUB-REPOSITORY-URL>
```

* Open the project folder:

```bash
cd movie-ticket-management-system
```

* Run the program:

```bash
python movie_ticket.py
```

#  Booking Process

* Login as a user.
* Select **Book Ticket**.
* Choose a movie.
* Enter booking date and time.
* Enter number of customers.
* Enter customer names.
* Receive a unique CUST number.
